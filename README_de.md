Speichern, bereitstellen und schützen Sie Anwendungsdateien mit Cloudflare R2. Verwalten Sie private Objekte, stellen Sie Downloads als Datenstrom bereit, gewähren Sie zeitlich begrenzten Zugriff, konfigurieren Sie Browser-Ursprünge, schließen Sie mehrteilige Uploads ab und wenden Sie Aufbewahrungsregeln an.
